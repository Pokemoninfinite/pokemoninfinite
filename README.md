# POKÉMON INFINITE

Directorio informativo de proyectos Pokémon creados por la comunidad.
Los juegos incluidos son FICTICIOS ([DEMO]). La plataforma no aloja ROMs ni archivos protegidos.

## Estructura
- index.html: web pública y panel de administración (#admin)
- js/games.js: catálogo (window.GAMES)
- assets/covers/ y assets/banners/: imágenes

## Publicar en GitHub Pages
1. Crea un repositorio público (por ejemplo, pokemon-infinite) y sube todos los archivos.
2. Settings → Pages → Deploy from a branch → main / (root).
3. Abre https://TU-USUARIO.github.io/pokemon-infinite/#admin

## Panel
Token de grano fino con permiso Contents: Read and write solo sobre este repositorio.
El token no se guarda; se pide en cada sesión.
Las imágenes deben pesar menos de 1 MB (recomendado 600×900 px para portadas).
